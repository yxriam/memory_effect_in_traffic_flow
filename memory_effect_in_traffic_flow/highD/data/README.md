# highD raw data (not distributed)

Place the 60 trajectory files `01_tracks.csv … 60_tracks.csv` from the highD dataset here.
The notebook reads them with `DATA_GLOB = './data/*_tracks.csv'` only when `RUN_COMPUTE = True`.

- Download: https://levelxdata.com/highd-dataset/ (free for academic use after registration).
- The licence does not allow redistribution, so this folder is git-ignored.
- Size: ≈ 0.9 GB raw (≈ 240 MB zipped, ≈ 110 MB with xz/7z).
